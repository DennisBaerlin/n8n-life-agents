# Career-Paket — Domänen-Regeln (lädt beim Arbeiten in `packages/career/`)

Career-Coach (`agent.career_advisor`): Job-Wechsel-Beratung + Profil/Plan + Job-Matching (werktäglicher Multi-Source-Scan Bundesagentur + Adzuna + JSearch, 👍/👎-Feedback). SoT `packages/career/db/*.sql` + `packages/career/db/migrations/`; Paket-Gesetze → `packages/CLAUDE.md`; Core-Maschinen → `packages/core/CLAUDE.md`; fn-Kontrakte → `docs/fn_catalog.md`.

- **Career ist durchgängig per_user — das Referenz-Paket für Person-Scoping:** `career_profile`/`career_preferences` = per_user/own_user_only (`core.context_scopes`), physisch `<base>__<person_id>`; `onboarding_state` und `job_matches` tragen `person_id NOT NULL` + FK; Plan-Persistenz über `agent.advisor_plans` mit `domain='career'` und realer `person_id`. Mechanik → `packages/core/CLAUDE.md` *context_scopes*, *Advisor-Plaene*, *Onboarding-Zustand*.
- `job_matches`: `source` ist eine CHECK-Liste (`bundesagentur|adzuna|jsearch|forwarded`), UPSERT-Key `(source, external_id, person_id)`; `board` nur bei `jsearch` gesetzt — Adzuna liefert StepStone-Inhalte ohne Board-Label (ein „via StepStone"-Feed gäbe es nur über den bezahlten Scraper, Owner-Budget = frei). Cross-Aggregator-Fuzzy-Dedup → `BACKLOG.md`.
- **Zeitspannen und Gehälter nur roh:** `career_start_date`/`skills[].since`/`target_date` statt Jahreszahlen (die Validatoren lehnen `experience_years`/`years_experience`/`timeline_years` ab), Gehalt mit `*_period`/`*_basis`; „vor ~N Jahren" und den Jahreswert (`career.fn_salary_text`) rechnen die Renderer. Fehlende Job-Bewertung = `score` NULL (nie gesendet, 7 Tage neu bewertet).
- Skill-Gap wird render-/review-at-fetch gerechnet (`career.fn_skill_gap`), nie gespeichert; die 4-Skala-Ordnung liefert `career.fn_skill_level_rank` (eine Quelle, kein ENUM).
- **Profil + Job-Vorlieben pflegt jede Person selbst:** `tool_set_profile_facts`/`tool_set_career_preferences` binden `agent.tool_set_own_context_facts` (Stufe `self`, kein Owner-Send); der Karriereplan (`career_planning`) bleibt über `save_/publish_plan` owner_only und ist im Fakten-Schreibweg gesperrt.
- Career-lokale Onboarding-Pflicht (`feature.career_onboarding_gate`, Default AN) nach `Load Config`: offen → Prompt-Abschnitt `## Career onboarding required`, nie ein Redirect (der Advisor ist selbst der Onboarding-Agent, ein Redirect sperrt den Menü-Auftrag aus). Crons fächern über `agent.fn_context_persons` je Person.
- Job-Feedback-Callback `job:` → `career.fn_handle_job_feedback` (Per-Item-Eigentum, `member_permeable`); `tool_record_job_match` steht im Write-Tools-Katalog (`docs/reference/packages.md`), Verb `record_*` → `packages/CLAUDE.md` *Verb-Taxonomie*.
- Optionale Adzuna-/JSearch-Keys im Manifest-`credentials`-Block (`docs/package-contract.md` §3.8), persistiert in `/etc/lifeagents/career.env`; fehlende Keys = graceful Bundesagentur-only. Host-Code trägt keine career-Literale (`contract_lint` Check 12).
